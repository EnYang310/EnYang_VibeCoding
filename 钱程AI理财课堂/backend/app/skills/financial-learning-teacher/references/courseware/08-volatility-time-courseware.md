# 课件 08｜涨跌不是信号：用时间看收益与波动

## 课件定位

训练学生用用途、期限、规则理解和可承受变化来阅读一次净值涨跌。只做金融素养教育，不预测市场，也不生成交易动作。

## 可引用知识

| evidence_id | 专业知识的教学化表达 | 权威依据 |
|---|---|---|
| `volatility-time.core-1` | 基金资产净值是基金总资产扣除总负债后的余额；净值变化反映资产价值变化，不能直接预测下一天。 | 基金资产净值与估值的定义。[^csrc-nav] |
| `volatility-time.core-2` | 不同基金类别的风险收益特征不同；收益预期越高，通常承担的风险也越大，但预期不是保证。 | 基金类别、风险收益特征与风险揭示。[^csrc-risk] |
| `volatility-time.core-3` | 分散可以降低单一证券带来的个别风险，但市场、流动性、管理等风险仍可能存在。 | 基金投资风险教育材料。[^csrc-risk-types] |
| `volatility-time.core-4` | 判断一笔钱能否承受变化，要结合投资目的、投资期限、经验、资产状况和风险承受能力。 | 基金适当性与风险揭示要求。[^csrc-suitability] |

## 专业补充与误区

- 回撤只描述从某个较高点到当前的下降幅度，不自带“下一步该买或卖”的结论。
- “长期”不等于必然盈利；时间只能改变等待空间，不能抹去不确定性。
- 热点、截图和群聊不替代来源核验、规则理解与个人任务判断。
