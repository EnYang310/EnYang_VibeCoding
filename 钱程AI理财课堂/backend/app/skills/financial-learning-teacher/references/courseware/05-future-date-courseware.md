# 课件 05｜目标、期限与阶段回看

## 课件定位

把“以后”翻译为日期、用途和下一步；不许诺目标会达成，不提供每月金额或借贷方案。

## 可引用知识

| evidence_id | 专业知识的教学化表达 | 边界 |
|---|---|---|
| `future-date.core-1` | 日期让目标可被检查，也帮助今天找到第一步。 | 可填月份或区间，不强迫精确。 |
| `future-date.core-2` | 日期、用途、收入或责任变了，可以重新规划；调整不等于失败。 | 不评价用户执行力。 |
| `future-date.core-3` | 一周能开始的动作和阶段回看，比未经核算的大口号更可执行。 | 不给储蓄指标。 |

## 专业补充与误区

- 长期不是死守原计划，而是愿意周期性检查期限、目标和现实条件。
- 日期提前时，优先回看任务冲突与可用性，而不是做收益预测。
- 大目标可拆成“补信息、设日期、做一次记录”等非金额化动作。

基金业协会投教指引倡导长期性、理性投资和风险收益认知；本课仅将其落到目标管理。[^amac]
