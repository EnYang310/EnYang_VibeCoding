# 杨恩 · Vibe Coding 作品集

> 这个作品集主要用来展示我的 **Vibe Coding 实践能力**：在没有完整工程团队支持的情况下，独立完成「想清楚要做什么 → 设计交互与策略 → 用 AI 协同把它真正跑起来」的全流程。
>
> 我希望未来在产品经理岗位上，能够同时承担 **需求洞察 + 产品策略 + 工程落地** 三类工作——不只是写 PRD，而是能用代码和 AI 把一个想法快速验证成可用产品。下面的两个项目，就是我在这个方向上的练手。

作品集包含两个项目：

1. **AIGC 电商海报及文案制作 Agent** — 多智能体协同的内容生成系统

## 一、AIGC 电商海报及文案制作 Agent

📄 项目文件：`AIGC电商海报及文案制作Agent.ipynb`

### 这个项目在解决什么问题

小微商家、个人创作者、新媒体运营者每天都要发布大量带货内容，但他们普遍面临三个痛点：**没预算请设计师、没时间打磨文案、缺乏对"爆款"的直觉判断**。市面上的 AI 绘图工具能出图，但出来的图常常"不像电商图"——没有卖点、没有调性、没有可直接用于投放的文案。

我想做的，是一个**真正能替代一个微型广告团队**的 Agent：用户只需要描述产品，系统就能在 30 秒到 1 分钟内输出一张可以直接挂上货架的电商主图，以及配套的标题、卖点和短文案。

### 我的逻辑思考

如果只让一个大模型"端到端"生成海报，结果往往是空洞的（AI 容易凭空捏造卖点、调性飘忽、配色乱用）。所以我把它**拆成了一个广告公司的工作流**：

- **Planner（项目主控）** — 拆解需求、统筹流程
- **Copywriter（文案）** — 必须先调用「卖点检索工具」拿到行业素材，再写文案；写完用「文案打分器」自评，不合格自动重写
- **Art Director（美术指导）** — 从「配色方案库」里选一套与品类调性匹配的配色，输出 Prompt
- **Visual Agent（出图）** — 调用图像模型生成最终海报

每个 Agent 都配了**专属工具**来约束它的发挥空间——这是为了解决大模型"放飞自我"的问题。文案不能凭空想，必须从我预置的 6 大品类词库里取材；配色不能瞎搭，必须从 7 套预设方案里挑。

技术栈用了火山引擎方舟的 Doubao-1.5-pro-32k（文本）+ Doubao-Seedance（图像），前端用 Gradio 快速搭了交互界面。

## 二、智聘 Agent · AI 智能简历

📄 项目文件：`AI智能简历.ipynb`
🌐 输出示例：`小明_2026-05-07.html`

### 这个项目在解决什么问题

主流的简历工具（超级简历、脉脉、BOSS 直聘的简历模板）几乎全是**面向白领设计的**：要求用户面对一张张空白表格，自己组织语言、提炼亮点、写"工作职责"。但中国有数亿蓝领工人，他们的真实情况是：**不知道该写什么、不会用专业术语包装自己、面对空白文本框就会卡住**。

一个工厂师傅的真实表达是「我在车间拧螺丝」，但招聘方想看到的是「负责产品组装流程，操作精密工具完成零部件装配，确保产品质量符合标准」。这中间的鸿沟，就是这个工具想要填上的。

### 我的逻辑思考

我做了三个关键的产品决策：

1. **从"填表"改成"对话"** — 蓝领用户对表单很陌生，但对聊天很熟悉（每天用微信）。所以整个简历是 AI 一句一句问出来的，按照「教育背景 → 个人信息 → 工作经历 → 技能 → 个人评价」的顺序逐项引导，用户只需要"答话"。

2. **AI 主动代写，而不是被动整理** — 这是和市面工具最大的差异点。当用户说"我在工厂拧螺丝"，AI 不会原文照搬，而是立刻代写出招聘方爱看的专业版本，并用「」包裹展示，让用户确认或修改。本质上是把**专业的语言能力下沉给了不擅长写作的人群**。

3. **完成度可视化** — 我设计了一套加权打分算法（基本信息 20% / 教育 20% / 工作 25% / 项目 15% / 技能 10% / 获奖 5% / 评价 5%），让用户随时知道自己的简历完成到了几分，而不是写完了才发现"漏了一大块"。

技术上，后端是 Flask + 火山引擎豆包 API，前端是单页 HTML，可以一键导出 PDF 简历。System Prompt 是这个项目的"核心灵魂"——我花了大量时间打磨它，让 AI 既能温和引导、又能在用户描述模糊时主动代写。

## 写在最后

这两个项目都不是"为了练 coding 而 coding"，而是我先观察到一类真实的人群和真实的痛点，然后用产品思维想清楚解决方案，再用 AI 协同把它落地成能跑通的原型。

对我来说，**Vibe Coding 的真正价值不在于写代码本身，而在于把产品经理从"只能写 PRD 等开发"的位置上解放出来**——能够独立验证想法、能够用工程语言和团队沟通、能够对方案的可行性有第一手判断。这是我希望在未来工作中持续打磨的能力。
