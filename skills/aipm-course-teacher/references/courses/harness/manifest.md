# 课程清单：harness

课程名称：LLM Harness 与 AI 产品经理系统课

适合人群：

- AI 产品经理实习生
- DeepSeek 或同类大模型公司的产品岗位候选人
- 需要先用人话理解、再逐步进入技术深度的学习者

教学目标：

1. 理解 Harness 是模型外部的能力系统。
2. 理解 Skills、Tools、Context、Workflow、Runtime、Eval、Governance、MCP。
3. 把概念转成 AI PM 的产品判断。
4. 准备 DeepSeek AI PM 面试表达。
5. 最终走向项目：Skill Hub、Agent Workbench、Eval Center、Coding Harness 或 MCP Gateway。

推荐起点：

- `## 专题 A：Harness 的前因后果：为什么它一定会出现`

项目路径：

1. DeepSeek Skill Hub
2. DeepSeek Agent Workbench
3. DeepSeek Evaluation Center
4. DeepSeek Coding Harness
5. DeepSeek MCP Gateway
